# 项目上下文

## 项目

- 名称：剪映视频助手
- 仓库：`jianying-video-assistant`
- 状态：WPF 兼容版开发阶段；素材、文案、背景音乐和安全草稿预览已形成首版闭环

## 产品目标

把“找素材、找文案、配音乐、生成剪映草稿”合并为一条轻量的成片准备流程，减少重复导入、跨页面选择和手工整理。

## 首版范围

1. 素材分类：文件夹导入、自动建议、快速纠错。
2. 内容文库：按用途检索片段，一键送入项目脚本。
3. 背景音乐：按情绪和时长推荐、试听、应用。
4. 剪映草稿：汇总当前项目，一次检查后生成草稿副本。

## 核心原则

- 以“当前视频项目”为中心，不要求用户先维护四套独立资料库。
- 每个功能都允许拖入即用，分类和元数据是渐进补充而非前置门槛。
- 常用动作最多两步完成；高级设置延后展示。
- 所有自动识别都可撤销、可人工覆盖。
- 永不静默修改用户的原始媒体和现有剪映草稿。

## 当前技术决策

- C# + WPF + .NET Desktop；因目标 Windows 环境中的空白 WinUI 程序也会原生崩溃，2026-09-14 经用户确认迁移界面层。
- 单项目解决方案，MVVM 分层；模型、ViewModel 和服务不依赖具体窗口框架。
- Windows 11 尝试使用 DWM 系统背景，不支持时回退为深色半透明实色背景。
- 初版使用内存项目状态，后续本地持久化采用 SQLite。

## 已实现的素材闭环

- 系统文件夹选择器、递归扫描图片/视频、完整路径去重。
- 基于文件名和目录名的五类规则建议，可在列表下拉框中纠正。
- 无权限目录统计、导入状态、文件类型/大小/相对路径展示。
- 扫描只读取素材，不移动、不重命名、不修改源文件。

## 当前首页约定

- 首页以“添加素材、添加视频文案、选择背景音乐、导出剪映草稿”四步呈现。
- 素材、文案、音乐和草稿预览四个入口均可操作，不保留只修改演示状态的假按钮。
- 不使用只改变演示状态的假按钮；每个入口必须能说明打开的界面和最终产出。

## 已实现的文案闭环

- 右侧覆盖面板、关键词搜索、用途筛选和完整句子预览。
- 选中文案加入当前项目脚本，脚本段落保持可见，可撤销最近一次加入。
- 重复文案允许采用但明确提示；文案和脚本当前仅保存在内存中。

## 已实现的背景音乐闭环

- 多选导入本地音频，支持 MP3、WAV、M4A、AAC、WMA、FLAC 和 OGG。
- 基于文件名和目录名建议情绪，支持情绪筛选、试听、应用、替换和撤销。
- 音频只按原路径试听，不复制、不修改；当前选择仅在本次运行期间保留。

## 已实现的安全草稿预览闭环

- 在单一面板检查素材路径、文案、背景音乐和安全输出规则。
- 通过 `JianyingDraftPreviewAdapter` 向应用工作目录写出独立预览目录、结构化清单和说明文件。
- 当前预览不是剪映原生草稿；取得真实样本并通过格式回归验证前，禁止写入剪映草稿目录。
