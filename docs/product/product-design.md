# 剪映视频助手：产品基线

## 1. 权威来源

本客户端是可独立安装和运行的 Windows 视频生产工具；`192.168.31.24:8000/workbench/` 仅作为现有 Web 产品的规则和功能对照。

- 客户端携带本地服务、SQLite 数据库、媒体工具和界面资源，不连接局域网服务器即可启动与使用本地功能。
- 客户端账号、产品、标签、素材、文案、音色、旁白、音乐、模型配置和草稿记录均保存在本机。
- Web 与客户端共享业务规则和经过验证的实现来源，但数据不自动同步。

此前“当前视频项目 + 四张任务卡”的设计与权威 Web 产品不一致，自 2026-09-15 起废止。

## 2. 信息架构

```text
视频生产
├── 素材归类
│   ├── 产品分类 / 产品名称历史输入
│   └── 逐视频自由标签
├── 内容文库
│   ├── 文案
│   ├── 音色库
│   └── 旁白与字幕
├── 背景音乐
├── 剪映草稿
├── 模型配置
└── 关于
```

客户端启动后直接进入“素材归类”，再按“内容文库 → 背景音乐 → 剪映草稿 → 剪映内精修”的顺序推进。不存在必须提前命名的“当前项目”，也不设置生产总览或 AI 视频入口。

主导航只切换可见页面，不销毁各业务页面。凡是提交后需要等待的任务，用户切换到其他页面后仍须继续运行；返回原页面时继续显示进行中状态，完成后显示结果或失败原因。音频转文案的待确认结果还必须保存到本机，页面刷新后也能恢复，只有保存到内容文库后才清除。

“关于”页展示产品用途与项目署名：开发工具为 Codex（OpenAI），项目协助者为 Gryps，联系微信为 `gryps_zhang`。联系信息仅作为客户端静态界面内容，不写入业务数据库或运行日志。

## 3. 业务规则

### 3.1 素材归类

1. 素材归类页不再提供独立的“产品与标签管理”子页，也不要求用户预先维护主数据。
2. “产品分类”和“产品名称”使用完全一致的历史下拉文本框，两者均可独立直接输入；空输入时展示最近使用的 5 条记录，输入文字时模糊查询全部历史。选择已有产品名称时自动带出它原有的产品分类。新输入在归类成功后自动保存，失败或取消不写入历史。
3. 一次导入批次只属于一个产品；同一产品名称不能同时归属多个产品分类，冲突时明确提示用户。
4. 待归类视频继续使用单选列表，切换视频只改变当前编辑对象，不批量勾选。
5. 视频标签采用与背景音乐相同的自由输入方式：点击单个视频的“标签”，在弹窗中使用中英文逗号分隔多个标签，可随时重新编辑或清空。每个视频最多 30 个标签、单个标签最多 80 个字符。
6. 自由标签在后台复用历史同名标签，并存入兼容既有素材关系的内部标签组；旧产品、分类、标签和已归类素材均保留，不做删除或迁移。
7. 用户可从当前批次删除误选视频；Windows 客户端只将该视频移出待处理列表，不删除原文件，Web 版只删除服务端暂存副本。
8. 确认后把本机暂存的原视频移动到素材根目录下的产品目录，并重命名为 `产品-标签1-标签2.ext`；重名使用数字后缀。
9. 移动前校验产品、路径、格式、媒体信息、标签和冲突；批次部分失败时回滚已经移动的文件，并保存原始路径、当前路径、时长、分辨率、产品和标签。

Windows 客户端使用原生文件选择器一次选择同一原始目录内的多个视频，并直接保留绝对路径；归类后的产品文件夹创建在该原始目录内。删除待归类项只会移出当前列表，不删除原文件。Web 版继续通过上传接口进入服务端暂存区。客户端不得再使用“商品、人物、场景、口播、其他”的文件名猜测分类。

### 3.2 内容文库

文案：

- 输入参考文案后由百炼分析语言风格、受众和专家角色，并生成 5 条候选。
- 每条候选必须“采纳”或“不采纳”；不采纳必须填写原因。5 条全部审核后才能继续下一轮。
- 不输入参考文案时使用全局已采纳文案快照；文案库为空则阻止生成。
- 文案库与分析迭代记录物理分离，文案支持新增、编辑、删除和产品关联。
- 音频转文案支持抖音短链接、本地视频或本地音频；识别结果经人工确认后才进入文案库。
- Windows 客户端解析抖音链接时优先使用系统 Microsoft Edge，也兼容 Chrome/Chromium；使用任务专用临时浏览器目录，不读取日常浏览器个人资料。页面使用 `blob:` 媒体源时，仅从本次临时会话的网络日志中筛选抖音可信媒体域名，任务完成后删除网络日志和临时目录。

音色库：

- 展示 Qwen3-TTS Plus 的 597 个官方基础音色，序号固定为 1–597。
- 支持关键词、性别、年龄和场景筛选。
- 试听音频首次生成后缓存，后续复用。

旁白与字幕：

- 用户可手工输入或从文案库模糊选择文案，再选择音色序号生成 TTS。
- 根据真实音频时长生成字幕时间轴；用户可确认、修订或删除。

### 3.3 背景音乐

- 支持上传本地音频/视频，或从短视频分享链接提取音频。
- 入库前验证存在有效音频并拒绝近乎静音的文件。
- 单播放器试听；支持重命名、自定义多标签和删除。
- 被草稿引用的音乐禁止删除。
- 不做 BPM、波形编辑、节拍点、卡点或自动裁切分析。

### 3.4 剪映草稿

- 文案、旁白字幕、背景音乐均为可选，但三者至少选择一项。
- 不向草稿写入任何视频媒体或视频片段；用户在剪映中自行添加、裁切和排序视频。
- 检测并确认剪映草稿目录，检测失败时允许手动指定并持久化。
- 生成真实剪映草稿文件，包括 `draft_content.json`、`draft_info.json`、`draft_meta_info.json`、相关 sidecar 和说明。
- 旁白、音乐复制到草稿自己的 `assets/audio`，不引用易失的上传路径。
- 草稿时长取字幕结束、旁白和音乐时长的最大值；只有文案时至少 5 秒。
- 同一素材组合重复时提示累计次数但不阻止；可重置计数基线。
- 草稿名带时间戳；目录冲突时追加 `-2` 等后缀，永不覆盖已有目录。
- 删除应用内草稿记录不删除磁盘上的草稿文件夹。
- 三个物料库的长名称或长文案在列表中保持紧凑省略，并提供可滚动的全文/详情查看；选中摘要不得撑宽页面。
- 生成草稿时完整原文保存在创建快照中；长文案按标点和可读长度拆分为连续文本片段，并在没有足够音频时长时延长草稿，避免把数千字压进单个五秒文本素材。

### 3.5 模型配置

- 文案生成、语音识别、字幕配音三张独立配置卡。
- 每张卡独立保存 API 地址、API Key 和模型 ID，支持连接测试与读取模型列表。
- 语音识别支持同步非实时 `qwen3-asr-flash` 和 `qwen-audio-3.0-asr-flash`；客户端按模型自动选择 OpenAI 兼容或百炼多模态接口。“读取模型列表”完整展示供应商返回结果，不按音频转文案能力筛选；百炼兼容列表未返回已验证的 `qwen-audio-3.0-asr-flash` 时补充该选项，但不自动替用户选择或保存。
- 读取模型列表的进行中、成功和失败结果必须显示在当前配置卡片内，不得只依赖页面顶部状态。
- 读取成功后在下拉列表下方显示按用途区分的选择建议，并从本次完整列表中列出匹配候选。建议使用 `qwenN.x-max`、`qwen-audio-N.x-asr-flash` 等模型家族与代际占位符，不把规则锁死在当前版本；例如文案模型可从 `qwen3.8-max` 演进到 `qwen3.9-max` 或 `qwen4.x-max`。
- 只记录真实业务调用日志；连接测试和模型列表请求不进入业务日志。
- 所有日志和界面必须脱敏 API Key；桌面端落盘前使用 Windows 当前用户 DPAPI 加密，发布包不得携带用户数据库。指定的对外交付包可携带 AES-256-GCM 认证加密的模型配置种子：首次启动仅在无本机配置时导入，立即转为该用户的 DPAPI 密文并删除解压目录中的种子。这不是防复制机制，完整包的使用限制由模型服务商侧实现。

## 4. 明确不开发

- 手工粗剪、代理视频、应用内视频时间线
- 自动选片、镜头相似度、节拍或卡点生产
- 成片渲染、成片库、爆款跟踪
- 无人值守批量生产、自动发布
- 框架库或版式编排

这些能力不得以“下一步优化”为由重新进入 Windows 客户端。

## 5. 桌面端交付规则

- 发布为 Windows x64 自包含目录，目标机无需安装 .NET、Python、FFmpeg 或系统 WebView2 Runtime。
- 应用启动随包本地服务，只绑定 `127.0.0.1` 随机端口；窗口关闭时结束服务进程。
- 数据目录为 `%LocalAppData%\JianyingVideoAssistant\Data`，升级应用不得覆盖或删除用户数据。
- 桌面数据目录只维护 `databases`、`logs`、`workspace` 三类运行目录；Web 专属的 AI 视频目录不得在客户端创建。
- 固定版 WebView2 使用 `%LocalAppData%\JianyingVideoAssistant\WebView2` 保存会话。
- 用户从 ZIP 解压后首次运行主程序时，自动在当前 Windows 用户的桌面创建或更新“剪映视频助手”快捷方式，无需管理员权限。
- 本地服务、显示进程或安装文件异常时必须显示原因、重试和数据目录入口。
- FFmpeg、FFprobe、yt-dlp 和临时浏览器等后台工具必须无控制台窗口运行，不得在用户处理素材、音频或草稿时闪现黑色命令行窗口。
- 顶部不提供日常“刷新”按钮，避免清除尚未提交的表单内容；启动失败保留明确的重新启动入口，F5 仅作为故障恢复快捷键。

## 6. 验收标准

- 桌面程序断开 `.24` 后仍可启动、登录并使用本地素材、内容、音乐、草稿和配置功能。
- 登录一次后重启客户端仍能恢复 Web 会话。
- 产品分类、产品名称分页、标签管理、素材归类、文案迭代、音色试听、旁白字幕、音乐、草稿和模型配置均使用本机数据。
- 发布包整体复制到目标机即可启动，不要求安装额外运行环境。
