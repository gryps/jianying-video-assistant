# 剪映视频助手配色系统

## 设计依据

本应用是 Windows 桌面效率工具，以 Microsoft Fluent 的中性分层和稀疏强调色为主要依据。界面大面积使用中性色，Microsoft Blue 仅承担主操作、选中、焦点和信息状态；状态颜色不单独传递含义，始终配合文字。

## 核心语义色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 画布 | `#F2F3F3F3` | `#F5202020` | 接近不透明的窗口底层，保留轻微系统背景材质 |
| 导航层 | `#F7FAFAFA` | `#F7181818` | 左侧栏，深色模式中低重要性表面更暗 |
| 内容层 | `#FAFFFFFF` | `#FA2C2C2C` | 卡片和密集信息的稳定表面 |
| 面板层 | `#FFFFFF` | `#292929` | 侧面板和高层内容 |
| 主要文字 | `#242424` | `#FFFFFF` | 标题、正文和关键数据 |
| 次要文字 | `#616161` | `#D6D6D6` | 辅助说明和元数据 |
| 弱边框 | `#E0E0E0` | `#454545` | 卡片分隔，不承担控件识别 |
| 控件边框 | `#8A8A8A` | `#8A8A8A` | 输入和按钮边界 |
| 主操作 | `#0F6CBD` | `#0F6CBD` | 唯一高强调按钮 |
| 主操作悬停 | `#115EA3` | `#115EA3` | 鼠标悬停 |
| 主操作按下 | `#0C3B5E` | `#0C3B5E` | 按下状态 |
| 键盘焦点 | `#0F6CBD` | `#479EF5` | 2px 焦点边框 |
| 成功 | `#107C10` | `#54B054` | 成功文字与图标 |
| 警告 | `#8A4B00` | `#FCE100` | 警告文字与图标 |

## 对比度基线

按最终合成背景计算：

| 组合 | 对比度 | 结果 |
| --- | ---: | --- |
| 浅色主要文字 / 内容层 | 14.87:1 | WCAG AA 通过 |
| 浅色次要文字 / 内容层 | 5.93:1 | WCAG AA 通过 |
| 白色文字 / 主操作蓝 | 5.38:1 | WCAG AA 通过 |
| 浅色控件边框 / 白色 | 3.45:1 | 非文字对比通过 |
| 深色主要文字 / 内容层 | 13.17:1 | WCAG AA 通过 |
| 深色次要文字 / 内容层 | 9.06:1 | WCAG AA 通过 |
| 深色控件边框 / 输入层 | 4.10:1 | 非文字对比通过 |
| 深色焦点 / 深色画布 | 5.80:1 | 非文字对比通过 |

## 实现规则

- 所有组件引用语义画刷，不在组件局部写十六进制颜色。
- 半透明仅用于窗口、导航和卡片的轻微材质融合；侧面板与输入表面保持稳定。
- 高对比度模式直接采用 Windows `SystemColors`，同时禁用系统背景材质。
- 新增颜色前必须先说明语义角色，并运行设计技能中的对比度脚本。
